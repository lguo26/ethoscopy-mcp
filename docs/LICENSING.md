# Licensing decision

This repository is intended to become open source, but it must not be published
without an explicit license.

Ethoscopy is currently distributed under GNU GPL version 3. The most direct
option is to license `ethoscopy-mcp` under GPLv3 as well. Before public release,
confirm dependency boundaries, contributor ownership, the exact SPDX
identifier, and whether any service components need different treatment.

Until that review is complete and the full license text is added, this scaffold
is not ready for public distribution.
